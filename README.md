# intro-to-web-dev

TouchStone task 2
In task 2, we will be creating 4 webpages in HTML only for a bakery client. The client name is North Star Bakery.
There will be 4 pages in total: index.html, products.html, about.html, contact.html.

Home: index.html

- Welcome messag
- "What we're known for" summary
- Hours and location snippet
- Featured item of the week

Also covers (At least two relevant images with meaningful alt text && One responsive image using the <pictures> element)

Products: products.html

- Product categories, such as breads, pastries, and cakes
- Brief product descriptions
- Pricing ranges, with no online checkout required

Also covers (One figure element with a caption && One audio or video element with fallback text)
